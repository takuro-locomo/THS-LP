# /pelvic-pain/ と /postpartum/ の役割分担（2026-11-03 決定）

「産後の骨盤帯痛と骨盤帯痛ページを統合できないか」という検討に対する結論。

## 結論：統合しない

| | /pelvic-pain/ | /postpartum/ |
|---|---|---|
| 検索意図 | **情報**（症状を調べている） | **商用**（買う人が探している） |
| 主なKW | 骨盤帯痛／仙腸関節 痛み／恥骨結合／骨盤ベルト 効果 | 産後 骨盤ベルト／産後 骨盤 サポーター／**産後の骨盤帯痛** |
| 対象 | **産後に限らない**骨盤帯痛全般 | 産後の方 |
| ページの仕事 | 研究の正本。「メタ解析では有意差なし」を正面から書いて信頼を取る | CV。トイレのたびに外さない→購入 |
| エビデンス | フル掲載（Damen 2002／Fitzgerald 2022／Lauridsen 2025・限界つき） | 3段落に要約し /pelvic-pain/ へ送る |

重複ではなく**ハブ&スポーク（要約＋正本）**。同じ文章のコピーは無い。相互リンクは
ナビ・本文・フッターで /pelvic-pain/→/postpartum/ が4か所、逆が3か所。

### 統合しない理由
1. 検索意図が逆。1ページで両方満たすとどちらにも最適化されない
2. /pelvic-pain/ は非妊娠期の骨盤帯痛も拾う設計。統合するとこの層を取りこぼす
3. 「売るページ」と「有意差なしを正面から書くページ」を混ぜると、CVRも信頼も落ちる
4. /pelvic-pain/ は2026-11-03新設・GSC登録直後。評価が付く前にURLを畳むのは損

## 代わりにやったこと（2026-11-03 実施）

- /pelvic-pain/：meta description とヒーローに「**産後に限らない**」を明記
- /pelvic-pain/：ディスクレーマ直後に**産後の方を /postpartum/ へ送る分岐ブロック**を新設
  （従来はページ下部のCTAに1か所あるだけだった）
- /postpartum/：keywords meta を新設し「**産後の骨盤帯痛**」を明示的に自分のものにする
- /postpartum/：description に「産後の骨盤帯痛」を追加。送り先リンクに「産後に限らない骨盤帯痛全般を扱っています」と補足

## 次の判断（2026-12 ごろ）

GSCの「検索パフォーマンス → クエリ」で、**同じクエリに対して2ページが入れ替わり表示されていないか**を見る。
入れ替わりが起きていれば共食い。そのとき初めて統合（どちらかに301）を検討する。
起きていなければ現状維持。
