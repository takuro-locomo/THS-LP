# @total_hip_supporter フォロワー獲得とコラボの進め方（2026-11-02）

ユーザー指示「適宜フォロワー（同業者や整体や整形外科医など）有用なフォロワーが増えるような挙動をして」→ 自動フォローはしない方針で「フォロー先リスト＋コメント文案」と「ハッシュタグ・コラボ」の両方を作る（ユーザー「両方」）。

## 0. 方針

- **フォロー・いいね・コメントは院長がアプリで手動で行う。** Claude による自動操作はしない（Instagram 規約で自動化が禁止／新規アカウントは操作制限を受けやすい／Chrome のログイン共有で他アカウントの作業に影響する）
- 1日の目安（公式の上限は非公開のため控えめに）: フォロー 10〜20／いいね 30前後／コメント 3〜5。開設1か月は下限で
- 目的は数ではなく「医療・リハビリ・介護の人に見つけてもらう」こと。フォロワーが少なくても、病棟・施設の導入につながる人が見ていればよい

### 選ぶ基準（全部満たすものだけ）

1. 最後の投稿が30日以内
2. 専門職本人か施設・団体の公式（プロフィールに職種・所属が書いてある）
3. フォロワー 1千〜5万人（大きすぎると反応が返らない、小さすぎると活動が止まっていることが多い）
4. 投稿の中身が教育・臨床の話題中心

### 避けるもの

- 「治る」「〇回で改善」など誇大な表現が多いアカウント（整体・サプリ系に多い）→ フォローはしてもよいが、**コメント・いいねで賛同しない**
- 患者さんの個人アカウント（症状の相談に発展しやすい。運用設計 §8 のとおり症状には答えない）
- フォロー返し目的の大量フォローアカウント、海外の業者
- 競合サポーターの販売アカウントへのコメント

## 2. 毎日10分のルーティン

1. 自分の投稿へのコメントに返信（最優先。2〜3分）
2. 上の検索語を1つ選び、「最近」タブから基準に合う人を5〜10人フォロー
3. そのうち2〜3人の最新投稿に、下の文案を参考にコメント（内容に触れて具体的に。定型文の貼り付けはしない）
4. フォロー中の専門職のストーリーズに1〜2件反応
5. 週1回、フォローして14日たっても反応がない人を整理（一度に外しすぎない。1日10人まで）

## 3. コメント文案（商品の宣伝・リンクは入れない）

## 5. コラボ投稿（共同投稿者）

Instagram の「コラボ投稿」は、相手が承認すると同じ投稿が相手のフォロワーにも表示される。新規アカウントにとって一番効く。

### 候補と順番

| 順 | 相手 | 内容案 | 注意 |
|---|---|---|---|
| 1 | 助野（公式アカウントがあれば） | #04「靴下メーカーが、サポーターを編む理由」や工場の様子をコラボで | 先方のアカウントの有無を確認する（ウェブ検索では見つからなかった） |
| 2 | 村中医療器（同上） | 取扱い・購入方法の回（#08）をコラボで | 同上 |
| 3 | 理学療法士の発信者（1〜2人） | 知識シリーズ第3回「姿勢」を、PT の運動解説と組み合わせて共同制作 | 謝礼・商品提供をする場合は投稿に「PR」表記（ステマ規制） |
| 4 | Studio NEXTE（@nexte.pilates.medipila） | 姿勢・骨盤の運動の回 | NEXTE のプロフィールに「上野医院ビル」とあり、医療機関名と商品が結びつく。**コラボにするかは院長判断** |

### 打診文案A（助野 山田様・松本様／メール）

```
件名：Instagram「コラボ投稿」のご相談（トータルHipサポーター）

助野株式会社
山田様、松本様

いつもお世話になっております。上野です。
先日はサイトのリンクの件でご連絡いたしました。

トータルHipサポーターのInstagram（@total_hip_supporter）を始めました。
つきましては、御社の編み技術や工場の様子をご紹介する投稿を、Instagramの「コラボ投稿」機能で、御社のアカウントと共同で出せないかと考えております。
コラボ投稿にすると、同じ投稿が両方のアカウントのフォロワーに表示されます。

・御社にInstagramの公式アカウントはございますか
・ある場合、コラボ投稿にご協力いただけますか
・工場や編み機の写真・動画で、使ってよいものがあればお送りいただけますか

原稿は事前にお送りし、ご確認いただいてから投稿します。
ご検討いただけますと幸いです。

上野琢郎
```

### 打診文案B（理学療法士の発信者／Instagram DM）

```
はじめまして。股関節サポーター「トータルHipサポーター」のアカウントを運用しています。
開発者は整形外科専門医の上野琢郎です。

〇〇さんの股関節（骨盤）の運動の投稿を、いつも参考に拝見しています。
いま「圧迫のサイエンス」という、研究をもとに圧迫の知識をまとめるシリーズを作っていて、「姿勢は運動と習慣でつくる」という回を〇〇さんの運動解説と一緒にお届けできないかと考えています。

形は Instagram のコラボ投稿（共同投稿）を想定しています。
内容・お礼の有無・表記（PR表記を含む）は、ご相談のうえで決めたいです。
ご興味があれば、詳しい企画をお送りします。突然のご連絡、失礼しました。
```

→ どちらも送る前に院長が確認。メールの送信は院長の承認後（既存ルール）。DMは院長がアプリから送る。
